NxtWave Build60 Growth Engine

A student growth and campus engagement platform designed to support the NxtWave Build60 initiative through student registration, growth tracking, campus ambassador engagement, budget monitoring, and strategic planning.

About the Project

The NxtWave Build60 Growth Engine provides a centralized dashboard for organizing and monitoring student acquisition activities. It focuses on reaching final-year engineering students through targeted campus channels, tracking registrations, and monitoring engagement performance.

The platform combines a growth dashboard with strategic planning tools to help teams understand their target audience, prioritize acquisition channels, and track progress toward campaign goals.

 Key Features

- Growth Dashboard:Monitor student acquisition progress and campaign performance.
- Student Registration:Register and manage participating students.
- Final-Year Student Tracking: Organize information related to target student groups.
- Ambassador & Squads: Support campus ambassador engagement and student squad activities.
- ₹2,000 Budget Ledger: Track the campaign budget and related spending.
- Pre-Signup Hook: Present a strategy for attracting students before registration.
- Squad Unlock Reward: Support engagement through squad-based rewards.
- Growth Plan & Brief: Document target audience analysis, acquisition strategies, channel prioritization, and campaign insights.
-Leaderboard: Display student engagement and performance rankings.

 Getting Started

Prerequisites

Install the following before running the project:

- [Node.js](https://nodejs.org/)
- npm
- [Git](https://git-scm.com/)

Installation

1. Clone the repository:

   bash
   git clone https://github.com/supriya32-k/nexus_stream.git


2. Navigate to the project directory:

   bash
   cd nexus_stream


3. Install the dependencies:

   bash
   npm install
  

4. Configure environment variables if required. Create a `.env` file using the variables expected by the application. Never commit API keys, passwords, or other secrets to GitHub.

5. Start the development server:

   bash
   npm run dev
   

6. Open the local application in your browser:

   
   http://localhost:3000
   

   If the terminal displays a different port, open the URL shown in the terminal.
